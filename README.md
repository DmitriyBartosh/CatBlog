# Котячий блог

React 19 + Vite. Требуется Node.js 22.12+.

```bash
npm install
npm run dev      # dev-сервер на http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # локальный просмотр сборки
```

Деплой на Vercel: настройки заданы в `vercel.json` (Vite, вывод в `dist`).
